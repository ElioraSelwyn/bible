# Read the Bible (BSB) — Eliora Selwyn™

The public site for [bible.elioraselwyn.com](https://bible.elioraselwyn.com/): the complete Berean Standard Bible, one HTML page per chapter.

This repository is the GitHub Pages source for that subdomain. The existing Blogger reader at https://www.elioraselwyn.com/p/read-bible.html is unchanged.

## Contents

- `index.html` — home page listing all 66 books
- One folder per book (for example `psalms/`, `acts/`, `1-samuel/`), each with a book page and one page per chapter
- `sitemap.xml`, `robots.txt`, and `404.html`
- `CNAME` — custom domain `bible.elioraselwyn.com`
- `.nojekyll` — publish the files as-is, without Jekyll

## URL scheme

- Home: `https://bible.elioraselwyn.com/`
- Book: `/psalms/`
- Chapter: `/psalms/122/`
- Verse: `/psalms/122/#v2`
- Range: `/psalms/121/#v1-2`
